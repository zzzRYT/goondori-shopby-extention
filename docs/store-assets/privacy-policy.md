# 군도리 샵바이 진열·배너 관리 — 정보 처리 방침

> 시행일: 2026-06-15 · 확장 버전: 0.0.6
>
> 본 방침은 브라우저 확장 프로그램 **「군도리 샵바이 진열·배너 관리」**(이하 "확장")가
> 어떤 정보를 어떻게 다루는지 설명합니다. 확장은 군도리 MD 운영자가 샵바이(Shopby)
> 어드민에서 진열·배너·상품심사 업무를 보조하기 위한 **사내 운영 도구**입니다.

---

## 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 개인정보 수집 | **하지 않음** |
| 자체/제3자 서버로 전송 | **하지 않음** (자체 서버 없음) |
| 데이터 판매·공유 | **하지 않음** |
| 광고·추적·분석(Analytics) | **사용 안 함** |
| 외부 통신 대상 | 운영자가 이미 사용하는 **샵바이 서비스로 한정** (`*.shopby.co.kr`, `shop-api.e-ncp.com`) |
| 저장 위치 | **브라우저 로컬**(`chrome.storage.local`)에만 저장 |

---

## 1. 처리하는 정보

확장은 다음 범위의 정보만 다룹니다.

### 1-1. 로컬에 저장하는 정보
- **상품심사 규칙 설정값**: 큐레이션/검수 규칙의 사용 여부(켜짐/꺼짐)와 사용자가 추가한
  규칙 정의. 브라우저의 `chrome.storage.local`에만 저장됩니다.
- 개인정보, 로그인 자격증명, 결제·정산 정보는 **저장하지 않습니다.**

### 1-2. 화면·API에서 읽어 들이는 정보 (저장하지 않음, 일시 처리)
- 운영자가 **이미 로그인한 샵바이 어드민**의 운영 데이터: 상품 등록·수정 심사 정보,
  상품/브랜드/진열/배너 목록 등.
- 이 정보는 사이드패널에 표시하거나 입력을 보조하기 위해 **메모리에서 일시적으로만**
  사용되며, 외부로 전송하거나 영구 저장하지 않습니다.

### 1-3. 수집하지 않는 정보
- 이름·연락처·이메일 등 개인 식별 정보
- 로그인 비밀번호·세션 토큰 등 자격증명 (브라우저가 관리하는 기존 로그인 세션을 그대로
  이용하며, 확장이 별도로 읽거나 저장하지 않습니다)
- 위치 정보, 기기 식별자, 광고 식별자
- 사용 행태·분석·텔레메트리 데이터

---

## 2. 처리 목적

- 상품심사 목록을 일괄 스캔하고 규칙 위반 및 **변경 사항(수정 심사)**을 표시하여 검수를 돕기 위함
- 진열·배너·브랜드 관리 화면에서 목록 조회 및 입력 보조를 제공하기 위함
- 위 목적에 필요한 최소한의 데이터만, 운영자의 조작 시점에만 처리합니다.

---

## 3. 권한 사용 내역

확장이 요청하는 권한과 사용 이유는 다음과 같습니다.

| 권한 | 사용 이유 |
| --- | --- |
| `sidePanel` | 작업용 사이드패널 UI 표시 |
| `storage` | 상품심사 규칙 설정값을 브라우저 로컬에 저장 |
| `activeTab` | 현재 보고 있는 샵바이 어드민 탭에서 심사/목록 영역을 찾기 위함 |
| `scripting` | 어드민 화면(및 내부 iframe)에서 목록·심사 데이터를 읽고 입력을 보조하기 위한 스크립트 주입 |
| 호스트 `https://*.shopby.co.kr/*` | 샵바이 어드민 화면을 읽고 입력을 채우기 위함 |
| 호스트 `https://shop-api.e-ncp.com/*` | 진열·브랜드 목록을 샵바이 Shop API로 직접 조회(읽기 전용 GET)하기 위함 |

---

## 4. 외부 전송 및 제3자 제공

- 확장은 **자체 서버가 없으며**, 처리하는 어떤 데이터도 군도리 또는 제3자의 서버로
  전송하지 않습니다.
- 발생하는 네트워크 통신은 운영자가 업무상 이미 사용하는 **샵바이 서비스로 한정**됩니다.
  - `*.shopby.co.kr` — 샵바이 어드민 화면
  - `shop-api.e-ncp.com` — 샵바이 Shop API (읽기 전용 조회)
- 데이터를 **판매·대여·광고 목적 공유하지 않습니다.**

> Chrome 웹스토어 *제한적 사용(Limited Use)* 정책 준수: 확장이 접근하는 데이터는 위에
> 명시된 사용자 대상 기능 제공 목적으로만 사용하며, 그 외 용도로 전송·판매·활용하지 않습니다.

---

## 5. 데이터 보관 및 삭제

- 모든 저장 데이터(규칙 설정값)는 **사용자 브라우저 로컬에만** 보관됩니다.
- 확장을 삭제하면 로컬 저장 데이터도 함께 제거됩니다.
- 규칙 설정은 확장 UI에서 언제든 변경할 수 있으며, 브라우저의 확장 저장소를 비우면
  즉시 삭제됩니다.

---

## 6. 보안

- 외부 저장소·자체 백엔드를 두지 않아 데이터 유출 표면을 최소화했습니다.
- 모든 통신은 HTTPS로 이뤄집니다.
- 확장은 운영자의 기존 인증 세션을 이용할 뿐, 자격증명을 별도로 수집·보관하지 않습니다.
